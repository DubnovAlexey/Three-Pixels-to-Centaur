# Фотоклуб «Объектив»

[English](README.md) · [עברית](README.he.md) · **Русский**

Лендинг школы фотографии: курсы и мастер-классы, галерея работ учеников, фотопоездки (в том числе «космическое сафари»), команда, отзывы, вопросы и ответы, формы связи. Самый большой из моих лендингов на HTML, CSS и JavaScript.

**Демо:** https://dubnovalexey.github.io/photoclub-objectiv/

## Возможности

- Десять разделов: о клубе, галерея, лучшие кадры, направления, космическое сафари, курсы, команда, отзывы, вопросы, контакты.
- Галерея с фильтром по категориям и лайтбоксом.
- Подробности о курсах и преподавателях в модальных окнах; форма связи и подписка на рассылку с сообщением об успехе.
- Светлая и тёмная тема (цветовые режимы Bootstrap) и выбор размера шрифта.
- Чтение текста вслух через синтез речи браузера.
- Появление блоков при прокрутке, плавная прокрутка и космические эффекты фона.
- Фоновый звук сгенерирован моими собственными скриптами на Node (`tools/generate-*.js`) — проблем с лицензией музыки нет.

## Стек

HTML5 · CSS3 · Bootstrap 5 · модули JavaScript (DOM, Web Speech API, `<dialog>`, Intersection Observer) · скрипты Node.js · GitHub Pages

## Как запустить

Откройте `index.html` в браузере или выполните `npm start`.

## Планы

- Настоящие фото (свои или со свободной лицензией, с подписями) вместо 32 картинок-заглушек.
- Расписание курсов из JSON с фильтром по уровню.
- Запись через Formspree, без своего сервера.
